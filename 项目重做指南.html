从零重做：BCG历史研究的荟萃分析

这个项目对应真实世界证据岗位中的“证据整理、统计分析、报告撰写”。你将学会四格表、RR/log(RR)、随机效应、异质性、森林图、预测区间及敏感性分析。

分析规范｜数据字典｜最终报告｜连续练习代码

范围先说清：我们复核既有公开13项研究数据集，没有完成新的系统检索、双人筛选或偏倚风险评级，因此不称“完成系统综述”。

0. 要回答的问题

这些历史研究中BCG组与对照组结核事件的RR如何？研究之间差异多大？改方差估计、限随机分配研究、逐一剔除研究后结论如何变化？

不要只追求一个显著合并RR。合并效应、异质性、预测区间和数据边界需要一起呈现。建议四次学习：①四格表和RR；②随机效应；③敏感性/探索；④报告与复核。

2. 先认识研究级数据

preview <- metadat::dat.bcg
print(preview)
table(preview$alloc)

一行是一项研究，不是一位患者。tpos/tneg是接种组事件/非事件，cpos/cneg是对照组。7项random、2项alternate、4项systematic，不能说“13项RCT”。

不同研究的随访、入组和环境可能不同。没有人时信息，因此分析的是随访窗口内风险比，不是发生率比。357347只是报告人数相加，不宣称跨研究患者已经去重。

3. 自己算一个RR和方差

a <- 10; b <- 90; c <- 20; dd <- 80
toy_rr <- (a/(a+b))/(c/(c+dd))
toy_logrr <- log(toy_rr)
toy_var <- 1/a-1/(a+b)+1/c-1/(c+dd)
print(c(RR=toy_rr,logRR=toy_logrr,variance=toy_var))

RR=0.5；logRR约-0.69315；方差0.13。接种组事件比例10%，对照20%。对数尺度便于正态近似和加权，最后取exp返回RR。

95%单研究区间：exp(logRR ± 1.96*sqrt(variance))。合并时不是直接平均各研究RR，也不是把所有事件人数相加后只算一个粗RR。

4. 构建效应量表和质量检查

source('R/01_data.R',encoding='UTF-8')
print(d[c('trial','tpos','tneg','cpos','cneg','yi','vi','RR')])
stopifnot(max(abs(d$manual_yi-d$yi))<1e-12)

escalc(measure='RR')生成yi=logRR和vi=方差；模块保留手算列，逐项核验。所有四格计数当前均大于0，设add=0，不做连续性校正。未来换数据出现0时先停下来选择方法，不能照抄一个0.5让它跑通。

数据快照MD5也被检查；哈希只是变更检测，不证明历史文献数据绝对正确。

5. 随机效应与REML

共同效应模型假定所有研究共享同一真实效应；随机效应允许各研究真实效应围绕一个平均值变化，研究间方差叫tau²。

my_fit <- rma(yi,vi,data=d,method='REML',test='knha')
print(my_fit)
print(predict(my_fit,transf=exp))

REML估计tau²，权重为1/(vi+tau²)。test='knha'使用Hartung-Knapp调整，不是把普通正态区间换个名称。13项研究时，均值区间需要考虑估计不确定性。

source('R/02_pooling.R',encoding='UTF-8')
my_weights <- 1/(d$vi+fit$tau2)
my_pooled_logrr <- sum(my_weights*d$yi)/sum(my_weights)
print(exp(my_pooled_logrr))
print(sum(d$weight_percent))

预期合并RR约0.48942，KH95%区间0.33007-0.72570；权重合计100%。这一步还核验手算加权均值和包结果一致。

6. 异质性与预测区间

print(pooled[c('tau2','I2','Q','Q_p','prediction_low','prediction_high')])

tau²约0.31324，I²约92.22%，异质性较大。这里I²用metafor模型定义，不应再套另一种Q公式要求数值完全相同。

预测区间约0.13588-1.76289，跨过1。均值效应区间不跨1与预测区间跨1可以同时成立：前者说平均真实效应，后者体现类似研究之间的分散。不能因此断言“每个地区效果都一样”或对个体给出接种效果预测。

7. 预设敏感性分析

source('R/03_sensitivity.R',encoding='UTF-8')
print(sensitivity)
print(loo)

三个角度：①用DL替代REML估计研究间方差，仍用KH推断；②只纳入7项random分配研究；③每次去掉一项研究，重新估计tau²和合并效应。

参考：DL合并RR约0.48962；随机分配子集RR约0.37872，95%区间0.20386-0.70357。差异可能由研究人群、设计等共同造成，不能直接归因于随机化本身。

逐一剔除不是删除“拖后腿”研究。全部13次结果应保留，不挑最显著的一次。研究规模很大也不自动意味着方法学质量最高。

8. 探索性元回归的正确边界

print(moderator_table)

mods=~I(ablat/10)让系数表示绝对纬度增加10度时logRR的变化，系数约-0.2910。I()告诉公式把除以10当算术操作。

这是研究层面的探索性关联。纬度可能与年代、设计、结核暴露等相关，存在生态偏差与混杂。不能把它解释成某个个体所在纬度的因果治疗效应。只有13项研究，不继续堆砌协变量找显著。

9. 森林图、漏斗图与报告

source('R/04_outputs.R',encoding='UTF-8')
finish(config$packages)

打开learning/my_output/REPORT.html。

森林图每行是研究RR和区间，方块大小反映权重，菱形是合并均值及区间；横轴对数尺度，1表示两组相同。漏斗图横轴logRR、纵轴标准误，图形不对称不自动证明发表偏倚；异质性和研究设计也会影响。

报告按：数据集从哪里来 → 效应量怎么算 → 主模型及预测区间 → 敏感性 → 探索性结果 → 证据限制。不要放虚构PRISMA流程图；如果今后真正开展系统综述，应另建检索式、数据库/日期、双人筛选、排除理由、数据提取和RoB记录。

11. 常见问题和自测

问题 排查
there is no package called… 从仓库根目录运行setup.R；确认.Rlibrary存在
数据哈希变了 核对metadat版本和数据，不直接修改expected_md5
合并值与网上示例不同 查REML/DL、knha/z、数据子集、效应量尺度
RR方向反了 确认t组始终为BCG、c组始终为对照
区间太宽 可能反映真实不确定性，不能靠删研究解决
森林图RR和模型系数不同 模型在log尺度，图用exp转换

自测：①手算玩具RR/方差；②解释为何大研究不占100%权重；③分别解释均值CI和预测区间；④说明为什么不是13项RCT；⑤说明为什么这不是系统综述；⑥不看代码讲清逐一剔除会重新估计哪些参数。
